- Website: <https://zonglinz.github.io/DSC180A-Methodology-4/>
- Assignment content: [index.md](index.md)
- Site configuration: [_config.yml](_config.yml)

## GitHub Pages

In **Settings > Pages**, select **Deploy from a branch**, then **main** and
**/ (root)**. GitHub Pages builds the Markdown with Jekyll.

## Local preview

With Ruby and Bundler installed:

```sh
bundle install
bundle exec jekyll serve
```

Open the local URL printed by Jekyll, including the
`/DSC180A-Methodology-4/` project path.
